# Случайная жизнь

Офлайн-симулятор современной жизни для Android. Начните со случайной семьи
в одной из шести стран и выбирайте, как проходит жизнь персонажа. Время
перематывается до следующей ситуации, а решения и важные последствия
попадают в дневник. После смерти открывается итоговая биография.

## Установка

Скачайте архив **random-life-apk** на странице успешного запуска GitHub
Actions. Распакуйте его и откройте **random-life.apk** на смартфоне.
Если Android попросит разрешить установку для приложения, из которого
открыт APK, подтвердите установку в системном диалоге. Для скачивания
артефакта Actions может потребоваться вход в GitHub.

Это тестовая сборка. Если два APK подписаны разными тестовыми ключами,
Android потребует удалить старую версию перед установкой новой. Удаление
приложения стирает сохранение. Для локальных сборок ключ сохраняется
в build/prototype.jks и используется повторно.

## Механики

Каталог содержит 48 ситуаций. Состав прохождения зависит от возраста,
предыдущих решений, состояния персонажа и случайного порядка подходящих
событий. Оценки влияют на поступление, навыки помогают найти работу,
доход и жильё меняют годовые расходы, отношения открывают семейные
события. Действия также влияют на здоровье и вероятность дожить до
поздних событий. Инвестиция и пенсионный резерв дают отложенный результат.

На экране персонажа видны происхождение и текущие параметры. После каждого
выбора игра сохраняется автоматически. Последняя жизнь открывается при
следующем запуске. Начало новой жизни заменяет сохранение.

## Устройство проекта

- web/events.js — тексты, возрастные окна, условия и эффекты решений.
- web/engine.js — генерация, возраст, бюджет, переходы и биография.
- web/app.js — мобильный интерфейс и запись в localStorage.
- android/ — Java-оболочка WebView. Ресурсы поступают из APK,
  сетевое разрешение отсутствует.
- test/engine.test.js — сценарные тесты на Node.js.
- .github/workflows/android.yml — тесты, сборка, проверка подписи и артефакт APK.

Для сборки нужны JDK 17 или новее, Android SDK Platform 35 и Build Tools
35.0.0. Скрипт использует штатные инструменты SDK. Для тестов движка
достаточно Node.js 20 или новее.

```sh
node --test test/engine.test.js
ANDROID_SDK_ROOT=/path/to/android-sdk bash android/build.sh
```

Для просмотра веб-интерфейса можно запустить из корня
`python3 -m http.server --directory web` и открыть localhost:8000.

## Ограничения прототипа

Экономика условная, а страны используют одну модель доходов и расходов.
Семья и карьера представлены агрегированными параметрами. Есть один
слот автосохранения без переноса между устройствами. Для игры требуется
обновляемый Android System WebView с поддержкой современного JavaScript.

Дальнейшее развитие — больше связанных цепочек решений, поимённые близкие,
различия между странами и экспорт сохранения.
